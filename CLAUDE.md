# CLAUDE.md

Este proyecto usa [`AGENTS.md`](./AGENTS.md) como fuente única de instrucciones para agentes. Léelo completo antes de trabajar en este repo.

## Notas específicas para Claude Code

- **Reporte obligatorio al terminar cualquier cambio:** Claude Code no carga los `.mdc` de `.agents/rules/` solos, así que lee y sigue [`.agents/rules/changes-report-rules.mdc`](./.agents/rules/changes-report-rules.mdc) antes de dar la tarea por cerrada. Si el cambio no parte de un plan, el reporte va en `.plans/results/small/`; si parte de un plan, en `.plans/results/<modulo-del-plan>/`. En el texto final di dónde quedó el reporte. Para comentar código nuevo o modificado aplica [`.agents/rules/metodos-comentarios-claros.mdc`](./.agents/rules/metodos-comentarios-claros.mdc).
